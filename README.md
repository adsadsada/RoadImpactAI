# 🛣️ Road Impact AI

> Система оценки влияния дорог на транспортную сеть города с помощью машинного обучения.

---

## 🧠 Что это такое

Road Impact AI предсказывает, насколько критична каждая дорога в городской сети.
Если убрать дорогу — как вырастет среднее время поездки по всему городу?
Система отвечает на этот вопрос за секунды, без полной симуляции.

---

## 🏗️ Архитектура
```
DATA LAYER → MODEL LAYER → API LAYER
Граф дорог     Симуляция      CLI
OD-матрица     Random Forest  (Streamlit — в разработке)
Датасет        Предсказание
```

Подробнее: [`docs/architecture.md`](docs/architecture.md)

## 🚀 Быстрый старт

### 1. Установка зависимостей
```
pip install -r requirements.txt
```

### 2. Генерация данных
```
python data/generate_graph.py
python data/od_matrix.py
python data/generate_dataset.py
```

### 3. Обучение модели
```
python model/train_model.py
```

### 4. Запуск API
```
# Посмотреть все дороги
python app/predict_api.py --list-edges

# Анализ конкретной дороги
python app/predict_api.py --from 7 --to 9
```

### Пример вывода
```
📊 Анализ дороги 7 → 9
==================================================

💡 Рекомендация: ✅ НЕ критична — можно перепрофилировать
🎯 Предложение: парк/пешеходная зона/велодорожка

🔍 Объяснение:
   • Текущая загрузка: 0.47x
   • Центральность дороги: 0.037
   • Альтернативных путей: 9
   • Свободное время: 3.3 мин
📊 Среднее время поездки: 3.73 мин
```

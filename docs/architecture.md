```

└─────────────────────────────┬────────────────────────────────┘
                              │
                              ▼
┌──────────────────────────────────────────────────────────────┐
│                    СЛОЙ СИМУЛЯЦИИ                            │
│                                                              │
│  generate_graph.py     →  граф города (NetworkX)            │
│  od_matrix.py          →  матрица Origin-Destination         │

└─────────────────────────────┬────────────────────────────────┘
                              │

```

## Компоненты

### data/generate_graph.py
Создаёт граф города из 15 узлов, сгруппированных в 4 района:
- **Центр** (0–4): плотная связность
- **Север** (5–8): кольцевая структура
- **Юг** (9–11): линейная цепочка
- **Восток** (12–14): треугольник

Между районами — **мосты** (критические дороги): единственные пути, удаление которых разрывает граф.

### data/generate_dataset_v2.py
Генерирует обучающие данные через симуляцию:
1. Для каждой дороги и уровня загрузки вычисляет признаки
2. Симулирует удаление дороги из графа
3. Измеряет изменение среднего времени поездки (impact)
4. Учитывает 5 периодов суток через коэффициент загрузки

**Признаки модели v2:**

| Признак        | Описание                                      |
|---------------|-----------------------------------------------|
| traffic       | Уровень загрузки (доля от capacity)           |
| capacity      | Пропускная способность дороги (авт/час)       |
| free_flow_time| Время проезда без пробок (мин)                |
| centrality    | Edge betweenness centrality                   |
| alternatives  | Число альтернативных путей (cutoff=4)         |
| is_critical   | Является ли дорога мостом (0/1)               |
| time_coeff    | Коэффициент времени суток (0.3–2.0)           |

### model/train_model_v2.py
Обучает `RandomForestRegressor` с параметрами:
- `n_estimators=150`
- `max_depth=12`
- `min_samples_split=4`

Целевая переменная: **impact** — относительный прирост среднего времени поездки при удалении дороги (0.0–1.0).

### app/streamlit_app.py
Веб-интерфейс Streamlit:
- Автоматически выбирает модель v2 (если доступна) или v1
- Визуализация графа с выделением критических дорог (красный)
- Выбор дороги и времени суток
- Прогноз impact + текстовое объяснение

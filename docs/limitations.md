# Ограничения RoadImpactAI

## Синтетические данные

Модель обучена на **полностью симулированных данных**. Граф города из 15 узлов и OD-матрица спроса сгенерированы программно, а не взяты из реальных источников (OpenStreetMap, данных транспортного департамента и т.д.).

**Следствие:** Предсказания корректно отражают логику алгоритма, но не обязательно совпадут с реальностью конкретного города без дополнительной калибровки.

## Упрощённая модель дорожной сети

- Граф содержит только 15 узлов и 21 ребро — реальный город имеет тысячи перекрёстков
- Не учитываются: светофоры, приоритеты полос, разрешённые повороты, односторонние улицы
- Пропускная способность дорог задана случайными значениями (20–80 авт/час)

## Модель трафика (BPR)

Используется формула Bureau of Public Roads (BPR), которая является упрощением:
- Не учитывает динамику трафика в реальном времени
- Коэффициенты α=0.15, β=4.0 — стандартные, не откалиброванные под конкретный город
- OD-матрица статична (не меняется со временем суток)

## Метрики модели

| Модель | MAE    | R²     |
|--------|--------|--------|
| v1     | 0.032  | 0.966  |
| v2     | 0.042  | 0.831  |

Высокое R² v1 объясняется небольшим и однородным датасетом (210 записей). Модель v2 честнее отражает сложность задачи благодаря большему разнообразию данных.

## Необходимые улучшения для продакшена

1. **Реальные данные**: интеграция с GPS-треками, данными транспортных датчиков, OpenStreetMap
2. **Динамическая OD-матрица**: использование данных мобильных операторов или систем видеонаблюдения
3. **Больший граф**: минимум 500–1000 узлов для реального города
4. **Калибровка BPR**: подбор коэффициентов под конкретный город
5. **Реальная валидация**: сравнение прогнозов с историческими данными о перекрытиях дорог
6. **Временны́е ряды**: учёт сезонности и долгосрочных трендов

## Этические ограничения

- Система предназначена для поддержки принятия решений, а не для их автоматизации
- Все рекомендации требуют проверки экспертами в области городского планирования
- Изменения дорожной инфраструктуры влекут социальные последствия, которые модель не учитывает
